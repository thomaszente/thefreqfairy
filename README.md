# The Frequency Fairy

A sound-healing app inspired by Victoria of [Healing by Victoria](https://www.healingbyvictoria.com/). The Fairy speaks and lip-syncs. The app includes a sacred gong to strike, a tuning fork studio, crystal bowls, angel messages, chakra portals, a walkable 3D fairy glade, astrology and Human Design charts, and Victoria's sessions.

Static site: no build step, deploys on Vercel as-is. Versions live on branches, and each branch gets its own Vercel preview link.
